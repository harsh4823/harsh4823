## 🚀 Featured Projects

### 🔐 [IAM Server — Keycloak-like Identity & Access Management](https://github.com/harsh4823)
> *Spring Boot · Spring Security · OAuth2/OIDC · JWT RS256 · Redis · PostgreSQL · Docker*

A production-grade identity server built from scratch, mirroring core Keycloak architecture.

- **Multi-tenant realm system** — isolated users, roles, and clients per realm
- **Full OAuth2/OIDC compliance** — Authorization Code flow, token introspection, OIDC Discovery (`.well-known`), JWKS endpoint
- **RSA RS256 signing** — persisted RSA key pairs per realm, auto-loaded on startup
- **Redis-backed token management** — access/refresh token lifecycle, revocation support
- **Realm-scoped login & self-registration** — per-realm login pages and user onboarding flows
- Containerized with **Docker Compose**
